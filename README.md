# Loading Screen Gold: A Tip in 200 Characters

Entry for the make.fun competition
`u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270`.

`main.py` (Python 3.13, standard library only, no network) writes one
sharp, funny loading-screen tip for stressed developers and AI coding
agents — a single line of at most 200 characters — to
`/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program asserts the output is exactly one line, non-empty, and
1–200 characters long before and after writing it.
